# 13 Nov - Programming Basics

## Algorithms aur Data Structures

- Algorithm kisi problem ko solve karne ka step-by-step method hota hai.
- Efficiency ko time complexity aur space complexity se measure karte hain.
- Solution readable banane ke liye comments, pseudocode, flowcharts aur UML diagrams use kar sakte hain.
- Achha solution correct, reliable, complete, modular, reusable aur scalable hona chahiye.

## Software Engineering

- RBAC ka full form Role-Based Access Control hai.
- Logging se application ke events aur errors record karte hain.

## Programming Concepts

- Turing machine aur computability theoretical concepts hain.
- Operators aur assignment values par operations karte hain.
- Branching ke liye `if`, `else` aur related statements use hote hain.
- Repeated work ke liye `while` aur `for` loops use hote hain.

## Programming Paradigms

- Batch aur procedural programming: Fortran.
- Structured programming: C, jahan functions important hote hain.
- Object-oriented programming ko OOP kehte hain.
- Functional programming mein lambda, `map` aur `filter` use hote hain. Haskell, ML aur OCaml examples hain.

## Non-Turing-Complete Languages

SQL/PL-SQL, HTML aur LaTeX general-purpose computation ke liye Turing-complete languages nahi hain.

## Compilation aur Python

- Compiler source code ko execution se pehle object code ya machine code mein translate karta hai.
- Python general-purpose language hai aur interpreted bhi hai.
- Python mein procedural, object-oriented aur functional programming styles support hote hain.
- Python shell/terminal se run ho sakta hai aur iski rich standard library hai.
- Python integers unlimited precision support karte hain.

## Python Built-in Data Types

`int`, `float`, `str`, `bool`, `None`, `list`, `tuple`, `dict` aur `set` common built-in types hain.

Python mein separate `char` type nahi hota. Ek character bhi `str` hota hai.

## Operators

- Arithmetic: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Bitwise: `&`, `|`, `^`, `~`, `<<`, `>>`
- Relational: `<`, `>`, `<=`, `>=`, `==`, `!=`
- Assignment: `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `**=`

Python relational comparisons chain karne deta hai, jaise `1 < 2 < 3`.

## Data Structures

- Iterable objects ko loop ke through visit kar sakte hain.
- String ordered aur immutable hoti hai.
- List ordered, heterogeneous aur mutable hoti hai.
- Tuple ordered, heterogeneous aur immutable hota hai.
- Dictionary key-value pairs store karti hai.
- Dictionary ki key immutable/hashable honi chahiye, lekin value koi bhi object ho sakti hai.
- Dictionary mutable hoti hai.
