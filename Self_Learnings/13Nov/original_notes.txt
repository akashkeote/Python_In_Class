## Special Values and Characters

- Python does not have a separate `char` data type.
- A single character is represented as a string, such as `"a"`.
- Boolean values: `True` and `False`.
- `None` represents the absence of a value.

## Data Structures

### Iterable Collections

- **String**: An immutable sequence of characters.
- **List**: An ordered, heterogeneous, mutable collection with no fixed size.
- **Tuple**: An ordered, heterogeneous, immutable collection.

### Key-Value and Unique-Value Collections

- **Dictionary**
  - Stores key-value pairs.
  - Keys must be immutable (hashable).
  - Values can be of any data type.
  - Dictionaries are mutable.
- **Set**
  - An unordered collection of unique elements.
  - Sets are mutable.

### Common Patterns

- `c`: Matches the character `c`.
- `[a-dp-z]`: Matches one character from the specified ranges.
- `[a-z]`: Matches one lowercase English letter.
- `[aeiou]`: Matches a vowel.
- `[^aeiou]`: Matches a character that is not a vowel.
- `c{m,n}`: Matches between `m` and `n` occurrences of `c`.
- `c+`: Matches one or more occurrences of `c`.
- `c*`: Matches zero or more occurrences of `c`.
- `\w`: Matches a word character.
- `\W`: Matches a non-word character.
- `\d`: Matches a digit.
- `\D`: Matches a non-digit character.
- `^`: Matches the beginning of a string.
- `$`: Matches the end of a string.
- `.`: Matches any character except a newline by default.
